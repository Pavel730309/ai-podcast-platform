## 📋 Инструкции для пользователя

### Загрузка на GitHub
1. Создайте репозиторий на GitHub с именем `ai-podcast-platform`
2. Следуйте инструкции в `UPLOAD_TO_GITHUB_INSTRUCTIONS.md`
3. Загрузите все файлы проекта

### Создание Docker образа
1. Следуйте инструкции в `DOCKER_INSTRUCTIONS.md`
2. Создайте и загрузите образ в Docker Hub

### Размещение на VPS
1. Подготовьте VPS сервер (Ubuntu 22.04)
2. Следуйте инструкции в `VPS_DEPLOY_INSTRUCTIONS.md`
3. Настройте домен и SSL
